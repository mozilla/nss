# FC_Logout

## Name

:::{container}
FC_Logout - log a user out from a token.
:::

## Syntax

:::{container}

```{code}
CK_RV FC_Logout(
  CK_SESSION_HANDLE hSession
);
```

:::

## Parameters

:::{container}
`hSession`

: [in] session handle.
:::

## Description

:::{container}
Logs the current user out of a USER_FUNCTIONS session.
:::
